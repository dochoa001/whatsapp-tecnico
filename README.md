# WhatsApp técnico para Atom

Presentación interactiva (unos 60 minutos) sobre la parte técnica de WhatsApp para empresas.

**Verla en línea:** https://dochoa001.github.io/whatsapp-tecnico/

## Qué cubre

| Bloque | Tema |
|---|---|
| 1 | Los 3 WhatsApps: normal, Business app y Business Platform (API) |
| 2 | Piezas de Meta: nuevo modelo de cuentas, verificación, calidad y límites |
| 3 | Cómo conectar la API: directo en Meta o con un proveedor (Embedded Signup) |
| 4 | Coexistencia: qué se pierde, qué cambia, reglas y diagnóstico |
| 5 | Ventana de 24 horas (simulador) y cobro por mensaje |
| 6 | Plantillas: categorías, partes, ciclo de vida y errores comunes |
| 7 | WhatsApp Flows (demo interactiva con el JSON que recibe el negocio) |
| 8 | Cambio de proveedor: antes (migración) y ahora (cuenta compartida) |
| 9 | Atom, documentación recomendada y preguntas de práctica |

## Cómo se navega

- Flechas del teclado, rueda del mouse o deslizando en el celular.
- Cada pantalla tiene su propio enlace (por ejemplo `#ventana` o `#flows`).
- Funciona en modo claro y oscuro.

## Fuentes

- Documentación de Meta para desarrolladores (coexistencia, nuevo modelo de cuentas, precios, plantillas, códigos de error, Flows), consultada en noviembre de 2026.
- Centro de ayuda de Atom, colección «WhatsApp API and Meta» (artículos de marzo de 2026).

Es un solo archivo `index.html`, sin dependencias aparte de Google Fonts.
